# Asphalt9Tas 0.8.0 · 保存、续录与兼容性修复（预发布）

可覆盖安装此前同签名正式版，无需卸载或清理录像。安装前建议导出重要存档。

## 本次修复

- 修复录制收尾时 `For input string: "2745156072"`：删除未参与保存决策的实时生命周期字段解析，继续使用已封存的完成状态判断结果。
- 修复续录冲线后反复出现 `checkpoint parent mismatch`：暂停草稿与完赛录像使用各自正确的保存路径，不再把完整录像交给草稿提升接口。
- 保持原有物理步长、输入回放及拼接时间轴逻辑不变。

## 相比上一公开版本的近期改进

- ARM64 地址读取及对象映射检查兼容带标记的指针；改进相关失败回执。这不是所有 Android 16 设备均已兼容的承诺。
- 调整比赛结束时的回调收尾顺序，先处理生命周期结束，再进行车辆对象检查，针对结束/续录阶段的失效对象问题。
- 游戏扫描优先批量查找候选进程，同次扫描合并身份读取，减少重复 Root 调用；保留必要的核心映射识别。
- 新选择录像时正确绑定对应目标 Tick；倒计时锚点未找到时给出更明确的说明。
- “加载到所选 Tick”增加点击反馈，错误同步显示在悬浮窗中。此项不是对所有无响应情况的全面修复承诺。
- TAS 操作要求显示悬浮标识；收起后保留用户摆放位置，优化按钮反馈和外观。悬浮标识不能防止裁剪、修改 APK，也不能证明某段视频没有使用 TAS。

## 验证状态与已知边界

- APK 构建、静态检查和签名验证通过；分支编辑离线测试 5 项通过，相关源码策略检查通过。
- 本次两项保存修复尚待测试者实机复测。建议测试：完整圈录制、前缀续录至冲线、中途暂停保存。
- 历史 900 帧基线的旧 observer 制品仍有哈希不一致警告；未修改历史清单，未将其算作通过。
- 此次不包含未完成的地图模型分析改动，也没有解决此前暂缓的 Slowmo 切回问题。
