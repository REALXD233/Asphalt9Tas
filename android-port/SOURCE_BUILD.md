# Source build inputs

The repository contains source and `config/runtime-manifest-template.json`.
The generated `assets/runtime` directory is intentionally not versioned. Its
manifest is bootstrapped from the template and refreshed with rebuilt artifacts.
Packaging includes only artifacts referenced by the generated manifest, on both
ARM64 and x86_64. Old carrier files in a local workspace are not packaged.

The native build also audits a reference game ELF, a reference LDPlayer libc,
and the historical 900-frame fixtures listed in
`baselines/known_good_900_exact_interval_v2.json`. These are external inputs,
not generated by cloning the repository. Do not publish game binaries or device
captures. The game ELF is a build-time reference fixture, not a restriction on
the APK's runtime Profile auto-generation.

From a clean source checkout, supply these inputs from the existing development
workspace or a private build-input bundle preserving the same paths:

```powershell
./android-port/prepare-build-inputs-v1.ps1 -ReferenceWorkspace 'D:\private\a9tas-build-inputs'
./android-port/build-g10-android-product-v1.ps1
```

The importer verifies the listed fixtures and refuses to overwrite a different
existing file. Configure the NDK path in the native script parameters/defaults;
the historical scripts default to the original developer's NDK location.
Android SDK 35 and JDK 17 reside in `android-port/.toolchains` as documented by
the main README. Therefore a checkout alone, without SDK/NDK and external
fixtures, is not a standalone native build environment.

## Host regression tests

After building the APK, run:

```powershell
python -B android-port/tools/test_android_branch_license_v1.py
python -B android-port/tools/test_stage_android_assets_v1.py
./android-port/test-library-host-v1.ps1
```

The Java regression runs production archive classes against synthetic files.
It uses host-only Context/Os substitutes under `tests/host`; those classes are
never included in the APK. Supply Maven Central's `org.json:json:20240303` as
`android-port/.toolchains/test-libs/json-20240303.jar` or use `-JsonJar`.
Expected SHA-256:
`3cf6cd6892e32e2b4c1c39e0f52f5248a2f5b37646fdfbb79a66b46b618414ed`.

Device testing remains necessary for pause/save, rapid Retry, and interruption
while a root command is pending. Host tests do not simulate game timing.
